## アクセス解析

**このサイトは Cloudflare Web Analytics でアクセス状況を計測しています。** 全ページにビーコン（JavaScript）を読み込んでいます。

Cloudflare は、この計測について公式ドキュメントに次のように書いています（原文は英語です。2026-09-02 に取得して確認しました）。

> Cloudflare Web Analytics does not collect or use your visitors' personal data.

> The JavaScript snippet (also known as a beacon) collects metrics using the Performance API, which is available in all major web browsers.

日本語にすると、訪問者の個人データを収集も利用もしないこと、計測はブラウザの Performance API を使って行われること、の2点です（訳は当サイトによるものです）。

出典: [About｜Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/)（2026-09-02 確認）

⚠️ ここに書けるのは、**Cloudflare が自社ドキュメントに書いている範囲まで**です。実際に送信されている項目の全量を当サイトで検証したわけではありません。詳細は上の出典と Cloudflare のプライバシーポリシーをご確認ください。

計測をやめたとき、または別の計測に変えたときは、この項目を書き直します。
